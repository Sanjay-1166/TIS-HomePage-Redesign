## Tulas International School — Homepage Redesign

A modern, responsive homepage redesign for **Tulas International School (TIS)**, created as part of a frontend development assignment.

The goal of this project is to transform the existing school homepage into a more modern, engaging and conversion-focused web experience while retaining the school's core identity and content.

https://tis-home-page-redesign-opal.vercel.app/

## Key Features

* Modern responsive homepage design
* Responsive navigation with mobile menu
* Animated hero section
* Scroll-triggered reveal animations
* Scroll progress indicator
* Interactive hover effects
* Responsive layouts for desktop, tablet and mobile
* Academics section with interactive cards
* Campus and student-life section
* Testimonials section
* Admissions call-to-action section
* Structured footer with navigation and contact information
* Smooth scrolling between sections

## Page Sections

### Hero

Introduces Tulas International School with a prominent visual section, supporting content and primary call-to-action.

### About

Highlights the school's background and key information such as its establishment, campus and student opportunities.

### Academics

Presents the academic experience through structured content cards and interactive visual elements.

### Campus & Life

Highlights student experiences beyond the classroom, including sports, arts and personal development.

### Student Voices

Presents the student experience through testimonial-style content cards.

### Admissions

Provides a clear call-to-action for visitors interested in learning more about admissions and contacting the school.

## Animation & UX

Framer Motion is used to create smooth entrance animations and scroll-triggered reveals throughout the page.

The design also includes interactive hover states, smooth scrolling and a scroll progress indicator to make navigation more engaging.

## Responsive Design

The homepage has been designed and tested across:

* Desktop
* Tablet
* Mobile

The layout adapts to different screen sizes while maintaining readability, spacing and usability.

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Sanjay-1166/TIS-HomePage-Redesign.git
```

### 2. Navigate to the project

```bash
cd TIS-HomePage-Redesign
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available through the local development URL provided by Vite.

## Production Build

To create a production build:

```bash
npm run build
```

The production files are generated in the `dist` directory.

## Deployment

The project is deployed using Vercel and connected to the GitHub repository.

Every update pushed to the main branch can be deployed through the connected Vercel project.
